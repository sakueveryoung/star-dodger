# 《星际躲避者 (Star Dodger)》v1.0 正式版

> 一款基于原生 **HTML5 Canvas 2D + ES Modules + Web Audio API** 开发的 2D 科幻霓虹风深空生存独立游戏。

---

## 一、项目概览与核心特性

- **美术风格**：深空蓝（`#080D21`）、霓虹青（`#21E6FF`）、电光紫（`#895CFF`）、霓虹粉（`#FF3BA7`）高对比科幻视觉体系。
- **程序化高清渲染**：支持 `devicePixelRatio`（上限 `2.0`）自适应高清渲染，100% 采用 Canvas 2D 矢量与渐变绘制，无需加载外部图片资源。
- **实时电子合成音效**：基于 `Web Audio API` 原创合成 7 类太空电子音效（菜单交互、跃迁启动、晶体收集、陨石碎裂、护盾受击、难度升级、结算），支持防重复叠音、实时主音量调节与静音持久化。
- **零 GC 抖动对象池架构**：陨石、能量晶体、推进器尾焰、定向岩石碎片与 `+10` 浮动文字全部由通用 `ObjectPool` 预分配复用，单帧逻辑+渲染耗时约 `0.38 ms`。
- **完整独立游戏 UI 与本地存档**：包含动态全息战机主菜单、操作说明、系统设置（音量/静音/全屏/恢复默认）、战斗遥测 HUD、暂停菜单、Game Over 结算面板与 `LocalStorage` 最高分存档（含隐私模式内存降级）。

## 二、游戏操作说明与生存法则

### 1. 操作说明（PC 键盘优先 + 移动端触控支持）

| 按键 / 输入方式 | 功能说明 | 适用状态 |
| :--- | :--- | :--- |
| **`W` / `↑`** | 控制飞船向上推进 | `PLAYING` |
| **`S` / `↓`** | 控制飞船向下推进 | `PLAYING` |
| **`A` / `←`** | 控制飞船向左推进（机身左倾） | `PLAYING` |
| **`D` / `→`** | 控制飞船向右推进（机身右倾） | `PLAYING` |
| **`P` / `ESC`** | 暂停游戏 / 恢复游戏 / 关闭二级弹窗 | `PLAYING` / `PAUSED` / `MENU` |
| **`R`** | 快速重新开始本局 | `PAUSED` / `GAME_OVER` |
| **`Tab` / `Enter` / `Space`** | 菜单按钮键盘焦点切换与确认触发 | 各菜单与弹窗 |
| **触控拖拽（移动端）** | 虚拟摇杆式方向滑动控制飞船移动 | `PLAYING` |

### 2. 核心规则与积分机制

1. **生命与护盾**：飞船初始拥有 **3 格生命值**。每次与陨石发生有效碰撞扣除 1 格生命，并立即激活 **1.2 秒六边形能量护盾无敌保护**（期间免疫连续碰撞伤害）。生命归零即触发 `GAME OVER`。
2. **积分获取**：
   - **生存得分**：在 `PLAYING` 状态下每累计生存 **1 秒** 自动获得 **+1 分**。
   - **能量晶体得分**：收集深空中旋转的高亮菱形能量晶体，每颗获得 **+10 分**。
3. **动态难度递增**：每生存 **20 秒** 难度提升 1 级（`LV.1` → `LV.2` → ...），新生成陨石的生成间隔由 `1.4s` 逐级递减至安全下限 `0.6s`，下落速度倍率由 `1.0x` 平滑提升至上限 `2.0x`，并带有防封路水平间距保护。

## 四、快速运行、测试与生产构建

### 1. 本地开发运行
```bash
npm install
npm run dev
```
启动后在浏览器访问 `http://localhost:5173/`。

### 2. 运行核心模块自动化单元测试
```bash
npm test
```

### 3. 生成正式生产版本 (`dist/`)
```bash
npm run build
npm run preview
```

### 4. 静态网站环境直接部署说明
执行 `npm run build` 后生成的 `dist/` 目录已配置相对路径（`base: './'`），且所有图形与音效均为原生代码实时生成，无任何外部静态路径耦合。可直接将 `dist/` 目录上传至 Nginx、Apache、GitHub Pages、Netlify、Vercel 或任意静态 HTTP 服务器即刻运行。
